# 숫자게임!

Up/Down 맞추기, 숫자야구, 스도쿠가 있는 웹 게임 모음입니다.

## 로그인 · 기록 저장

- 회원가입/로그인 데이터는 브라우저 localStorage에 저장됩니다 (서버 없이 GitHub Pages에서 동작)
- 로그인한 계정마다 프로필(닉네임·사진)과 최고 기록이 따로 저장됩니다
- 다른 기기·브라우저와는 동기화되지 않습니다

## 최고 기록

| 게임 | 기준 |
|------|------|
| 횟수맞추기 | 최소 시도 횟수 (자릿수 + 난이도별) |
| 숫자야구 | 최단 시간 (자릿수별) |
| 스도쿠 | 최단 시간 (난이도별) |
